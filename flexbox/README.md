# Flexbox

This directory contains HTML and CSS files demonstrating Flexbox layout techniques.

## Files

- `0-index.html` & `0-styles.css` - Basic flexbox introduction
- `1-index.html` & `1-styles.css` - Flexbox container properties
- `2-index.html` & `2-styles.css` - Flexbox item properties
- `3-index.html` & `3-styles.css` - Flexbox direction and wrapping
- `4-index.html` & `4-styles.css` - Flexbox alignment
- `5-index.html` & `5-styles.css` - Flexbox justify content
- `6-index.html` & `6-styles.css` - Flexbox align items
- `7-index.html` & `7-styles.css` - Flexbox order
- `8-index.html` & `8-styles.css` - Flexbox grow and shrink
- `9-index.html` & `9-styles.css` - Flexbox basis
- `10-article.html` & `10-styles.css` - Article layout with flexbox
- `11-article.html` & `11-styles.css` - Advanced article layout
- `12-article.html` & `12-styles.css` - Complex article layout
- `13-article.html` & `13-styles.css` - Responsive article layout
- `14-article.html` & `14-styles.css` - Complete article layout
- `images/` - Image assets for the project
